## Graph, provenance and API verifier obligations

Pin every source URL/commit, archive and file digest, declared export and lock
integrity. Retain all runtime, type, development, build and example roots as
distinct sets. Resolve every selected edge; investigate dynamic imports,
loaders, subprocesses and generated code. Lexical searches alone are not graph
proof. Unselected upstream dev tools remain explicitly excluded historical
evidence, not part of the runnable owned graph; no hidden test/build dependency
may be dropped to make the graph appear clean. Relevant missing gitlinks need
their actual pinned source/license evidence before reuse.

Build in a fresh isolated root from the exact committed source, with native
config/lock, explicit online transport then frozen/cached replay, no ambient
warm-cache assumption and no safety-bypass flags. Record actual argv/grants,
source/emitted hashes and export behavior. Review all emitted code; compile
exit zero alone is insufficient. Keep pinned source-stage and emitted-stage
graphs separately and prove the correspondence. Reproduce build outputs or
explain each allowed nonsemantic difference before accepting them.

The public route must demonstrate document-stream parsing, stable node identity,
bounded token spans, explicit edit/render, diagnostics and separate conversion
interfaces. An adapter may map conceptually to parseDocument/setIn/toString,
but it must disclose every difference; matching method names is insufficient.
Token inspection false/true preserves the original case setting. Original source
retention must not depend on public token exposure. Unknown tags do not execute
constructors; invalid documents cannot pass as successful editable documents.

## Original Y-14 run protocol, after gates

Freeze the [crosswalk](y14-crosswalk.json) hash and all 28 original rows, inputs,
case arguments and proposed output/splice hashes before loops. Preserve two
attempts per row: 56 process attempts per complete condition. Primary and
independent fresh condition each cover all 28; controls have a separate named
denominator. Do not substitute a representative subset. No warm-up rule is
invented for these non-resource cases.

For each row retain source bytes, decoded text, document/node graph, diagnostics,
tokens where exposed, requested edit, byte splice, rendered bytes and physical
file output. Compare exact output hex/SHA with the proposed acceptance bytes;
reparse under the frozen schema and compare all intended/unchanged semantics.
Use an independently reviewed semantic oracle or explicit fixture expectations,
not the same serializer's self-attestation alone. No-op bytes, BOM/CRLF/newline,
comments/blank lines, scalar styles/chomping, directive and unrelated node spans
are mandatory comparisons. All four threshold counters must be zero.

The two block-scalar edits add a root entry after the original EOF; separately
verify original scalar content including trailing newlines. Numeric edits retain
their exact locations; schema interpretation of original `01` must be explicit.
Both token modes must have identical semantic/byte results. Public token absence
in false mode is intentional; missing internal preservation evidence is not.
Record parse/convert/render durations separately, not as a new benchmark claim.

Reuse the verified supervisor with actual no-grant parser, explicit file grants,
denied controls, wall/output/RSS/observation/parent-exit stops, checkpoint and
cleanup proof. Freeze limits before execution; retain all failures and unrun
rows on a stop. New file-policy implementation additionally needs cooperating
writer conflict, forbidden symlink, pre/post-commit cancellation, orphan ownership,
partial-write detector and real versus injected/NotCapable controls. The design
does not claim those policy mechanisms were implemented by prior runtime trials.

Independently compare candidate input/output and temp/destination bytes and
states before cleanup. Lossless packets retain helper sources, every failed
draft, emitted code, actual streams/records, graphs/configs/locks and original
fixtures. Extract into new scratch and rerun semantic/physical checks and
negative audits; no old absolute scratch path may be required. A negative audit
must reject wrong input hashes, altered unrelated bytes, missing rows, false
token evidence and incorrectly erased unsupported dispositions.

## Stop rules and residual scope

Each subsequently commissioned slice must be bounded and ledgered with a maximum
five failed conditions, including unusable verifier/packet drafts; reassess at
four before exhaustion. Missing approved owner, source/graph/license edge,
unreproducible build, policy violation, unbounded resource behavior or failed
fidelity threshold stops dependent work. Preserve original scope and request a
reviewed redesign/decomposition; do not quietly normalize outputs, delete cases
or retry under broader permissions. No package installation/evaluation occurs
under this design's current authority.

including guide exposure and representative source review. Arc03 owns existing
test-permission, guide/book/compiler/formatter and integration obligations.

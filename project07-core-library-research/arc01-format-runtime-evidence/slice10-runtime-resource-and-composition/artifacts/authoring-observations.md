first failure. This is a retained authoring observation within existing
compiler/guide obligations, not a source fix supplied here. Full-manifest reuse
requires exact-set checks: an FF-only dispatcher would omit valid DB scope.

intended command. Physical source-temp copies and directory manifests make
captured replay independent of old absolute scratch paths.

real/user/system observations remain separate. Sampled RSS can miss short-lived
processes. Primary/replay timing variation cannot establish a performance change.

provenance; a trailing LF difference is explicitly retained.

# Navigation policy

Actual Markdown and HTML links to migrated files follow the new destination.
Root-relative planning citations in inline code use the new planning-root path.
Sentences that narrate historical moves and fenced historical commands retain
their source context; they are not rewritten into false accounts of history.
Links to retained source files use the original immutable source commit.
The manifest supplies source branch, commit, blob, original path, import commit,
move commit and destination for every tracked migrated file. Original broken
references and future artifacts are reported separately from introduced breaks.

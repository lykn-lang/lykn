2026-11-07. Scope: NE-C09 task repair, independent source acceptance and original
four parser observations, same approved Sol6.1 High CDC/Luna6 High CC. This is
process learning, not an additional acceptance gate or policy change.

The full normal bar was decisive. Five finite controls and a valid core did not
establish compatibility: existing grouped-bind and switch tests exposed introduced
regressions. Independent reproduction rejected those candidates before release.
Two explicit Operator budget overrides stayed visible; their approval authorized
another bounded attempt, never accepted source. The final source and four parser
observations now independently pass; no production integration follows.

CDC design/review missed both emission cardinality and structural child roles.
A function-prefix form can expand into sibling declarations; a numeric switch
clause is not a computed call. Applying generic Value recursion lost those facts.
The final correction preserves the existing statement expansion and dedicated
switch roles without reverting real computed-call Value semantics. Next similar
change should review role AND output cardinality at touched boundaries and run
the nearby existing grouped/switch tests early. This recommendation is grounded
in these regressions, not a claim of universal coverage.

Several private tests initially passed for weak or incorrect reasons: the class
await discriminator, loop fallback-presence predicate and AST-head accessor did
not test the intended distinction. Their bodies/results and corrected meaningful
red are preserved. Source/API misreading is an authoring/review finding; it does
not automatically establish a guide or compiler defect. Freeze and falsify the
smallest discriminating assertion before using its green as evidence.

lint conflict later replaced by the distinct sibling-scope control, wrong cwd,
format edition, cached-product setup flags and copied hash wording. One wrong-cwd
receipt was overwritten and a transient Rust draft lacks a separately saved body;
only actual surviving raw/tool-text strength is claimed. Use unique attempt homes
before invocation, actual executable paths/hashes and source-supported APIs. Do
not manufacture missing history or call setup0cases a semantic failure.

demonstrate a broader model-efficiency trend.

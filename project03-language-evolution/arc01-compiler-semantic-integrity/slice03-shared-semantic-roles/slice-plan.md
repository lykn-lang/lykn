At c9, classifier/forms.rs357–841 has ExprPosition and raw positional policies;
emitter/forms.rs3220–3300 duplicates KernelChildProfile. Classifier
is_value_function_tail mirrors emitter STATEMENT_FORM_HEADS/function-body logic.
Both already honor as_form_head; never replace resolution with spelling tests.
Emitted body cardinality matters: emit_body expands grouped binds into sibling
const declarations, whereas emit_expr packages multi-output forms in a block.
Only variadic statement-sequence segments flatten; fixed if branches, headers,
call arguments and the outer switch clause list remain single children.

1. Introduce private `mod semantic_roles` (no pub reexport) containing closed
   Copy/Debug/Eq enums for **expression use** Statement/Value/Tail, **child
   role/cardinality** (single Value, single Statement, variadic StatementSequence,
   inherited single/sequence), and shared body policy. Binding/name/syntax-data
   boundaries remain explicit grammar adapters, not unused future enum variants.
   Keep existing public emitter::context::ExprContext exactly intact; exhaustive
   private conversions preserve all3states, validator treats Value/Tail consumed.
   Prefer small pure borrowed helpers/static profiles, no visitor framework,
   generic adapter exposing internals, interior mutability or new dependency.
2. ONE authoritative normalized-kernel positional policy, used by both validator
   and lowering, keys on **SExpr head via as_form_head**. Unknown/bound/computed
   callees use single Value callee/arguments. `if`: Value condition, single
   branches inheriting use (lowerer's existing value-if intercept remains).
   `while` AND `do-while`: Value test, ALL later StatementSequence children.
   `for`: three Value headers, all later StatementSequence. Iteration forms:
   binding grammar then Value iterable, all later StatementSequence. Declaration
   names/patterns are grammar, initializer is Value. Preserve inherited block/
   label/try adapters and module/declaration syntax, not a universal raw walk.
   Delete replaced parallel profile/table/predicate code from BOTH consumers.
3. Actual do-while order is test first/restbody: native codegen emit.rs720–731,
   JS compiler.js1162+, both existing do-while test files. Native pass2 has no

   Thus guide00:919's body-first example is a pre-existing documentation error,
   not authority for a new surface normalizer. Correct it narrowly and explain
   ordered statement body segments; update Lykn reference's kernel-loop note.
   Preserve guide functional if/? equivalence and source-first language goals.
4. Share the existing statement-form/function-tail decision: nonvoid func/fn/
   lambda may consume a final value (if-with-else included), prefixes Statement;
   void/genfunc/genfn are statement bodies, preserve genfn :yields header and
   source keyword-clause parsing. Return insertion remains its lowerer's job;
   distinguish inherited Tail from the Value child consumed before wrapping.
   A consumed do/match body has Statement prefixes and Value final expression;
   unconsumed body is Statement throughout. No global await scanner rewrite,
   implicit Promise adoption, new return semantics or C02/C05 repair.
5. Keep grammar-specific adapters explicit: match pattern metadata/Value subject/
   Value guard/clause sequence; switch Value discriminant, structural clause
   test versus raw default marker, clause-body sequence; class property names/
   parameter/binding/pattern/module/quote-data boundaries owned by their existing
   grammars. Do NOT recursively reinterpret a pattern, parameter list, class

### Private API shape (engineering sketch, not executed code)

Use `pub(crate)` only inside the private module for cross-phase helpers:
`ExprUse { Statement, Value, Tail }`; `ChildRole { Value, Statement,
StatementSequence, Inherit, InheritedSequence }`;
`BodyPolicy { Statements, FunctionValueTail }`.
`fn normalized_child_role(head: &SExpr, argument_index: usize) -> ChildRole`
is the shared flat-policy entry: it calls as_form_head itself; ordinary/resolved
bound heads return Value. No new unconstrained string-dispatch entrypoint.
`fn is_statement_form(expr: &SExpr) -> bool` and
`fn function_body_use(expr: &SExpr, index: usize, len: usize, policy: BodyPolicy)
-> ExprUse` replace the duplicated predicates. Nonvoid/fn callers select
FunctionValueTail, void/generator callers Statements before this function.
`fn sequence_use(index: usize, len: usize, parent: ExprUse) -> ExprUse` returns
Statement prefixes, consumed Value final child (Tail remains consumed), otherwise
Statement. Implicit return construction remains the emitter's existing layer.

Binding/name/pattern/class/import/export/quote-data syntax is NOT made another
evaluation enum or another parser. Phase adapters preserve actual existing
grammar-owned slots and invoke shared expression-use/sequence rules only for
their evaluated children; do not send structural containers into the flat call
walker. Retain their current parsing/error ownership. Flat declaration/iteration
binding slots retain the existing grammar-aware Statement adapter; fixed if
branches inherit a SINGLE child, not sequence flattening. InheritedSequence
flattens only when the actual inherited use is Statement; retain existing
value/tail behavior without inventing a value-producing block/label contract.
Shared switch adapter
may use a small `switch_clause_test`/body-slice helper for both phases, preserving
default marker/span/empty/nonlist behavior. Names/property markers legitimately
use as_atom in these grammar adapters; dispatch identity remains as_form_head.
Do not add unused future variants, expose a private module for integration tests,
or expand into a generic pattern/function/module grammar rewrite. This limits
the common core to actual duplicated consumption/cardinality policies while
making specialized phase boundaries explicit and tested by preservation cases.

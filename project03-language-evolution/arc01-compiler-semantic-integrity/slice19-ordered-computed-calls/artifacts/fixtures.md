## F1 — computed-member-ordered-throws.lykn

```lykn
(bind trace (array))
(bind getter-error (new Error "getter"))
(bind argument-error (new Error "argument"))
(func actual-method :args (:any earlier :any middle :any later) :returns :any :body
  (trace:push "call")
  (array this:label middle))
(func make-target :args (:any mode) :returns :any :body
  (bind target (obj :label "receiver"))
  (Object:defineProperty target "method"
    (obj :get (fn ()
      (trace:push "getter")
      (if (= mode 1) (throw getter-error))
      actual-method)))
  target)
(func invoke-computed :args (:any mode) :returns :any :body
  (bind key (obj))
  (Object:defineProperty key Symbol:toPrimitive
    (obj :value (fn (:any hint) (trace:push hint) "method")))
  (bind answer
    ((get
       (do (trace:push "base") (make-target mode))
       (do (trace:push "key") (if (= mode 3) (return 93)) key))
     (trace:push "first")
     (do (trace:push "arg") (if (= mode 2) (throw argument-error)) 8)
     (trace:push "last")))
  (trace:push "after")
  answer)
(func observe :args (:any mode) :returns :any :body
  (try
    (return (invoke-computed mode))
    (catch problem
      (return (array (= problem getter-error)
                     (= problem argument-error)
                     (instanceof problem TypeError))))))
(console:log (JSON:stringify
  (array (observe 0) (observe 1) (observe 2) (observe 3) trace)))
```

Expected exact stdout:

```text
[["receiver",8],[true,false,false],[false,true,false],93,["base","key","string","getter","first","arg","last","call","after","base","key","string","getter","base","key","string","getter","first","arg","base","key"]]
```

The getter and argument failures are actual source throws and
retain exact error identity. The key's `Symbol.toPrimitive`
runs at actual GetValue once, before the getter and first arg.
Old mode 3 is expected to use the key wrapper's 93 as a property
name, evaluate the args and catch TypeError rather than exit 93.
Retain the actual old complete trace and module.

## F2 — computed-member-no-prefix.lykn

```lykn

  ((get 1 2) 3))

  (fn (:any first :any second)
    (fn (:any third) (array first second third))))
(bind receiver (obj :read-entry (fn (:any n) (+ n 1))))

  ((kernel:get receiver "readEntry") 3))
(console:log (JSON:stringify (array (call-bound bound) (call-pure receiver))))
```

Expected `[[1,2,3],4]` plus LF and empty stderr, both old and
current. Compare complete old/current generated bytes for each
backend. Genuine lexically bound `get` is an ordinary computed
call. The checked explicit escape is an ordinary member call.
No support function or import in either generated module.
